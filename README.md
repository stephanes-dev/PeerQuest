# PeerQuest

Distributed, peer-to-peer architecture enables real-time processing and auto-scaling across a scalable network platform.

PeerQuest is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/PeerQuest.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PeerQuest is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
